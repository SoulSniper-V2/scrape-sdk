---
title: Jina Reader
description: r.jina.ai scrape and s.jina.ai search.
---

```ts
import { jina } from "scrape-sdk/jina";

jina({ apiKey: process.env.JINA_API_KEY }) // key optional for light use
```

Scrape uses `GET https://r.jina.ai/{url}` with `Accept: application/json` (not SSE). Search uses `POST https://s.jina.ai/` with `{ q }`.
