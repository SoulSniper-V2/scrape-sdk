---
title: Browserbase
description: Fetch API markdown — not a Playwright session.
---

```ts
import { browserbase } from "scrape-sdk/browserbase";

browserbase({ apiKey: process.env.BROWSERBASE_API_KEY!, proxies: false })
```

Uses `POST https://api.browserbase.com/v1/fetch` with `format: "markdown"` and `X-BB-API-Key`. This does **not** create a browser session and does **not** execute JavaScript. For SPAs, use Firecrawl. For JSON, pass a `schema` (Fetch `format: "json"`).
