---
title: Tavily
description: Extract and search with Bearer auth.
---

```ts
import { tavily } from "scrape-sdk/tavily";

tavily({ apiKey: process.env.TAVILY_API_KEY! })
```

`scrape()` maps to `POST https://api.tavily.com/extract`. `search()` maps to `POST https://api.tavily.com/search`. Auth is `Authorization: Bearer`, not `api_key` in the body.
