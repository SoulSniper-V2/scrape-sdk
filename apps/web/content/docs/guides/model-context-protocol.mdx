---
title: Model Context Protocol
description: Official MCP SDK stdio server with web_fetch and web_search.
---

```json title="mcp.json"
{
  "mcpServers": {
    "scrape-sdk": {
      "command": "npx",
      "args": ["-y", "scrape-sdk-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-...",
        "TAVILY_API_KEY": "tvly-...",
        "JINA_API_KEY": "jina_..."
      }
    }
  }
}
```

A copy lives at `examples/mcp.json`. The skill at `skills/scrape-sdk/` ships a sibling `mcp.json` so skill hosts can auto-attach the server.

Built with `@modelcontextprotocol/sdk` (`McpServer` + `StdioServerTransport`), so Claude Desktop and Cursor get a real `initialize` handshake.

Without keys, `web_fetch` and `web_search` still work via Jina + local. `map_site` / `crawl_site` / `extract_json` appear when a configured provider supports them.

`web_fetch` truncates to 20_000 characters by default and returns `truncated` + `charCount`. Raise `maxChars` only when you need the rest of a page.

`fromEnv()` reads `FIRECRAWL_API_KEY` (or `FIRECRAWL_KEY`), `TAVILY_API_KEY`, `JINA_API_KEY`, `SPIDER_API_KEY`, `BROWSERBASE_API_KEY`.
