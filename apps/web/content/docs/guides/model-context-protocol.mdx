The **Model Context Protocol (MCP)** server allows AI desktop applications and IDEs to execute live web extraction during your conversations without writing any glue code.

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "scrape-sdk": {
      "command": "npx",
      "args": ["-y", "scrape-sdk-mcp"]
    }
  }
}
```

---

## Zero-Configuration Mode (No API Keys Needed)

`scrape-sdk-mcp` is designed to work **100% out-of-the-box**. 

If you do not specify any environment variables or API keys, the server automatically routes requests to **Jina Reader** (`r.jina.ai`) with secondary failover to the offline **Local Cheerio** engine. You get instant, sub-second markdown extraction immediately.

## Client Setup Guides

<Tabs items={["Claude Desktop", "Cursor IDE", "Windsurf / Hermes"]}>
  <Tab value="Claude Desktop">

### macOS Configuration
Open `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "scrape-sdk": {
      "command": "npx",
      "args": ["-y", "scrape-sdk-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-your-api-key-here"
      }
    }
  }
}
```

### Windows Configuration
Open `%APPDATA%\\Claude\\claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "scrape-sdk": {
      "command": "npx",
      "args": ["-y", "scrape-sdk-mcp"]
    }
  }
}
```

Restart Claude Desktop. You will see the **hammer icon** 🔨 indicating `scrape_web` is active.

  </Tab>

  <Tab value="Cursor IDE">

Add to your project root at `.cursor/mcp.json` or in **Cursor Settings > Features > MCP**:

```json
{
  "mcpServers": {
    "scrape-sdk": {
      "command": "npx",
      "args": ["-y", "scrape-sdk-mcp"],
      "env": {
        "FIRECRAWL_API_KEY": "fc-your-key",
        "TAVILY_API_KEY": "tvly-your-key"

    }
  }
}
```

Cursor Composer and Agent mode will now automatically scrape URLs referenced in your coding prompts.

## Configuring API Keys via "env"

To enable dynamic JavaScript rendering with Firecrawl or entity extraction with Tavily, pass your credentials in the `"env"` object:

| Environment Variable | Description | Fallback Behavior |
| :--- | :--- | :--- |
| `FIRECRAWL_API_KEY` | Enables Firecrawl v1 JS rendering engine | Falls back to Jina if missing or 429 rate-limited |
| `TAVILY_API_KEY` | Enables Tavily raw research extraction | Falls back to Jina if missing |
| `DEFAULT_PROVIDER` | Set primary default (`"firecrawl"`, `"jina"`, `"tavily"`, `"local"`) | Defaults to `"firecrawl"` if key exists, else `"jina"` |

## Tool Interface: scrape_web

When connected, the AI agent is equipped with the following tool signature:

```json
{
  "name": "scrape_web",
  "description": "Scrape any webpage and extract clean token-optimized ATX markdown with multi-provider failover.",
  "parameters": {
    "url": {
      "type": "string",
      "description": "The target HTTP or HTTPS webpage URL."
    },
    "format": {
      "type": "string",
      "enum": ["markdown", "html", "text"],
      "default": "markdown"
    }
  },
  "required": ["url"]
}
```

## Example Agent Prompts

Once configured, simply paste any link into your conversation:

* *"Summarize the release notes at `https://nextjs.org/blog/next-15`."*
* *"Read `https://docs.stripe.com/api` and write me a TypeScript helper to create subscription webhooks."*
* *"Extract the pricing table from `https://resend.com/pricing` and output it as a JSON schema."*

The model will automatically invoke `scrape_web`, receive clean ATX markdown with 0 token bloat, and generate your response.
