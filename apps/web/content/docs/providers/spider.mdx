---
title: Spider.cloud
description: Single-page scrape and multi-page crawl.
---

```ts
import { spider } from "scrape-sdk/spider";

spider({ apiKey: process.env.SPIDER_API_KEY! })
```

Uses `POST https://api.spider.cloud/scrape` for one URL and `POST https://api.spider.cloud/crawl` for a site. Not `/v1/crawl`.
