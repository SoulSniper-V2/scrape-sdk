---
title: Installation
description: Install scrape-sdk, the CLI, and the MCP server.
---

## Package

```bash
npm install scrape-sdk
# or
bun add scrape-sdk
```

## Agent skill

```bash
npx skills add SoulSniper-V2/scrape-sdk --skill scrape-sdk
```

## Subpath exports

| Subpath | What it is |
| :--- | :--- |
| `scrape-sdk` | `createScrapeClient`, `fromEnv`, types, errors |
| `scrape-sdk/firecrawl` | Firecrawl **v2** adapter |
| `scrape-sdk/jina` | Jina Reader + Search |
| `scrape-sdk/tavily` | Tavily Extract + Search |
| `scrape-sdk/spider` | Spider `/scrape` and `/crawl` |
| `scrape-sdk/browserbase` | Browserbase **Fetch API** |
| `scrape-sdk/local` | Cheerio + turndown |
| `scrape-sdk/ai` | `createTools` → `web_fetch`, `web_search`, `map_site`, `crawl_site`, `extract_json` |

MCP is a separate package: `npx scrape-sdk-mcp`.
